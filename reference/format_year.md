# Format a year into the correct short FY format

Format a year into the correct short FY format

## Usage

``` r
format_year(year)
```

## Arguments

- year:

  Year of the file to be read, you can specify multiple years which will
  then be returned as one file. It will be converted to short FY using
  `format_year()`.

## Value

Year correctly formatted into short FY e.g. '1718'
