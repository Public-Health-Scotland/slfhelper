# Recid name / description lookup

A [tibble](https://tibble.tidyverse.org/reference/tibble-package.html)
containing the names and description of the recids. To be used with the
`recid` parameter when reading the episode files.

## Usage

``` r
recids
```

## Format

A [tibble](https://tibble.tidyverse.org/reference/tibble-package.html)
with 18 rows and 2 variables:

- recid:

  The short-form recid

- Description:

  A description of the recid
