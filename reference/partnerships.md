# HSCP name / code lookup

A [tibble](https://tibble.tidyverse.org/reference/tibble-package.html)
containing the names and codes (hscp2018 configuration) of partnerships.
To be used with the `partnership` parameter when reading files.

## Usage

``` r
partnerships
```

## Format

A [tibble](https://tibble.tidyverse.org/reference/tibble-package.html)
with 31 rows and 2 variables:

- partnership_name:

  The official name of the Partnership

- hscp2018:

  The hscp2018 standard code S370000??
