A [tibble](https://tibble.tidyverse.org/reference/tibble-package.html)
containing an example cohort of CHI numbers under different variable
names. It is used for testing and to illustrate examples. It is likely
that many of the 'chi numbers' are not valid.

## Usage

``` r
chi_cohort
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 100
rows and 2 columns.
