# Social Care Partnership names / sending location code / LCA code lookup

A [tibble](https://tibble.tidyverse.org/reference/tibble-package.html)
containing the names and codes (sending location/LCA configuration) of
social care partnerships.

## Usage

``` r
sc_partnerships
```

## Format

A [tibble](https://tibble.tidyverse.org/reference/tibble-package.html)
with 32 rows and 3 variables:

- partnership_name:

  The official name of the Partnership

- lca:

  The coresponding LCA code 05L

- sending_location:

  The sending_location standard code 100L

## Details

To be used with the `sc_partnerships` parameter when reading files.
